# 16S Amplicon Sequence Analysis for Predicting Colorectal Cancer
This website provides an example of an analysis report for 16S amplicon dataset with **the goal to identify key biomarkers of gut microbiome for colorectal cancer prediction**. The example comprises of a detailed report on gut microbiome abundance, host characteristics and their association with colorectal cancer.

The example presented **utilizes a public dataset available online** from (Zackular et al., 2014). The study investigated the potential of gut microbiome for predicting cases of colorectal cancer. 

We used raw sequences (i.e., FASTQ files) from the study and applied our **[in-house processing pipeline](https://pankajchejara23.github.io/16S-workflow/)** to generate relative abundance dataset of microbiome.

## References
